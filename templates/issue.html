Форма выдачи
Начните вводить номер — список отфильтруется
Отмена
Порядок выдачи
  1. Возьмите инструмент, посмотрите инвентарный номер на нём
  2. Введите номер в поле поиска
  3. Выберите инструмент из отфильтрованного списка
  4. Укажите сотрудника, получающего инструмент
  5. Нажмите «Выдать»

В списке только доступные инструменты (на складе).

Выданные, ремонтируемые и списанные не отображаются.
